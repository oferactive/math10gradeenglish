Non-Polynomial Functions

The absolute value function, the square root function, \(\tfrac1x\) and \(\tfrac1{x^2}\): their domains, graphs, symmetry, asymptotes and how fast they change. Practice for this unit is in the workbook.

1. The absolute value function

The absolute value \(|x|\) is the distance of \(x\) from 0 on the number line, so it is never negative:

\(|x|=\begin{cases}x, & x\ge 0\\ -x, & x\lt 0\end{cases}\)
for example \(|5|=5\) and \(|-5|=5\)

The graph is symmetric about the y-axis, so \(|x|\) is an even function. It decreases with constant rate \(-1\) for \(x\lt 0\) and increases with rate \(1\) for \(x\gt 0\).

\(|x-a|\) is the distance between \(x\) and \(a\). This makes equations and inequalities easy to read:

Example 1

Solve \(|2x-1|=7\).

Solution.

\(2x-1=7\Rightarrow x=4\), or \(2x-1=-7\Rightarrow x=-3\).

2. The square root function

\(\sqrt{x}\) is the non-negative number whose square is \(x\). It is defined only for \(x\ge0\), and its values are never negative.

Domain: \(x\ge0\). Range: \(y\ge0\). The function always increases, but more and more slowly: from \(x=0\) to \(x=1\) it rises by 1, from \(1\) to \(4\) also by 1, from \(4\) to \(9\) again only by 1.

Its domain is not symmetric, so \(\sqrt{x}\) is neither even nor odd.

Example 2

Solve \(\sqrt{x+6}=x\).

Solution.

Square both sides: \(x+6=x^2\Rightarrow x^2-x-6=0\Rightarrow x=3\) or \(x=-2\).

Check: \(x=3\): \(\sqrt9=3\) ✓. \(x=-2\): \(\sqrt4=2\ne-2\) ✗.

The only solution is \(x=3\).

Important: squaring both sides can create false solutions, because a negative number and a positive number have the same square. Always check the answers in the original equation.

3. The function \(\tfrac1x\)

\(f(x)=\dfrac1x\) is defined for every \(x\ne0\). Its graph is a hyperbola with two separate branches.

Asymptotes. As \(x\) gets close to 0, \(\tfrac1x\) becomes very large in size: the graph approaches the line \(x=0\) (a vertical asymptote). As \(|x|\) grows, \(\tfrac1x\) approaches 0: the graph approaches \(y=0\) (a horizontal asymptote).

Symmetry. \(\tfrac{1}{-x}=-\tfrac1x\), so \(\tfrac1x\) is an odd function, symmetric about the origin.

Rate of change. The function decreases on \(x\lt 0\) and decreases on \(x\gt 0\). But it is not decreasing on its whole domain: \(f(-1)=-1\lt f(1)=1\). The gap at \(x=0\) breaks the pattern.

4. The function \(\tfrac1{x^2}\)

\(g(x)=\dfrac1{x^2}\) is also defined for every \(x\ne0\), with the same asymptotes \(x=0\) and \(y=0\). But its values are always positive, and \(\tfrac1{(-x)^2}=\tfrac1{x^2}\), so it is an even function: both branches lie above the x-axis, symmetric about the y-axis.

It increases on \(x\lt 0\) and decreases on \(x\gt 0\). Near 0 it grows faster than \(\tfrac1{|x|}\), and far away it approaches 0 faster.

5. Finding the domain

The domain is the set of all \(x\) for which the expression can be computed. In this grade two rules matter:

  • A denominator cannot be zero.
  • The expression under a square root cannot be negative.
Example 3

Find the domain of \(f(x)=\sqrt{5-x}\) and of \(g(x)=\dfrac{1}{x+2}\).

Solution.

\(5-x\ge0\Rightarrow x\le5\).

\(x+2\ne0\Rightarrow x\ne-2\).

Example 4

Where is \(\dfrac1{x^2}\gt \dfrac1x\)?

Solution.

For \(x\ne0\), multiply both sides by \(x^2\), which is positive: \(1\gt x\).

Answer: \(x\lt 1\), \(x\ne0\), that is \(x\lt 0\) or \(0\lt x\lt 1\).

6. Common mistakes

  • Writing \(|a+b|=|a|+|b|\). This is false when \(a\) and \(b\) have opposite signs: \(|3+(-5)|=2\), but \(|3|+|-5|=8\).
  • Solving \(|x-2|=5\) and keeping only \(x=7\). There are two numbers at distance 5 from 2.
  • Writing \(\sqrt{x^2}=x\). The correct rule is \(\sqrt{x^2}=|x|\).
  • Not checking solutions after squaring both sides of an equation with a square root.
  • Saying that \(\tfrac1x\) is decreasing everywhere. It decreases on each branch separately, not across \(x=0\).
  • Multiplying an inequality by \(x\) without knowing its sign. Multiply by \(x^2\) (always positive), or split into cases.

7. Check yourself

Short exercises to check that you understood the explanation. Try each one before you open the solution. For more practice, go to the workbook.

  1. Compute \(|-4|+|3|\) and \(|-4+3|\).

    Show solution

    \(4+3=7\) and \(|-1|=1\).

  2. Find the domain of \(\sqrt{2x-6}\).

    Show solution

    \(2x-6\ge0\Rightarrow x\ge3\)

  3. Solve \(|x+3|=5\).

    Show solution

    \(x+3=5\Rightarrow x=2\), or \(x+3=-5\Rightarrow x=-8\).

  4. Write down the asymptotes of \(y=\tfrac1x\).

    Show solution

    \(x=0\) (vertical) and \(y=0\) (horizontal).

  5. Is \(\tfrac1{x^2}\) even, odd, or neither?

    Show solution

    \(\tfrac1{(-x)^2}=\tfrac1{x^2}\): even.

  6. Solve \(\sqrt{x}=7\).

    Show solution

    \(x=49\)

  7. For which \(x\) is \(\sqrt{x}\lt x\)?

    Show solution

    For \(x\ge0\): \(\sqrt x\lt x\) when \(x\gt 1\). (At \(x=0\) and \(x=1\) they are equal, and between them \(\sqrt x\) is larger.)

  8. Find the average rate of change of \(\tfrac1x\) on \([1,4]\).

    Show solution

    \(\dfrac{\tfrac14-1}{4-1}=\dfrac{-\tfrac34}{3}=-\tfrac14\)
