Transformations and Operations on Functions

Shifts, stretches and reflections of graphs, the families \(a(x-p)^n+k\), \(a\sqrt{x-p}+k\) and \(\tfrac{a}{x-p}+k\), and new functions built by adding, multiplying and dividing. Practice for this unit is in the workbook.

1. Shifting a graph

Every transformation answers one question: where does each point of the original graph go?

New functionWhat happens to the graphPoint \((x,y)\) moves to
\(f(x)+k\)up \(k\) units (down if \(k\lt 0\))\((x,\ y+k)\)
\(f(x-p)\)right \(p\) units (left if \(p\lt 0\))\((x+p,\ y)\)

The horizontal shift often surprises students: in \(f(x-3)\) there is a minus sign, but the graph moves right. The reason: the new function reaches the value \(f(0)\) when \(x-3=0\), that is, at \(x=3\).

2. Stretching and reflecting

New functionWhat happens to the graphPoint \((x,y)\) moves to
\(a\cdot f(x)\), \(a\gt 0\)vertical stretch by \(a\) (a shrink if \(0\lt a\lt 1\))\((x,\ ay)\)
\(-f(x)\)reflection in the x-axis\((x,\ -y)\)
\(f(-x)\)reflection in the y-axis\((-x,\ y)\)

A stretch keeps the roots in place (\(a\cdot 0=0\)) and keeps the x-coordinates of the extreme points. A negative \(a\) stretches and also flips the graph.

An even function does not change when reflected in the y-axis, because \(f(-x)=f(x)\). An odd function reflected in the y-axis gives the same graph as reflecting in the x-axis.

Example 1

The point \((2,5)\) is on the graph of \(f\). Which point is on the graph of each new function?

Solution.

\(f(x)+3\): \((2,8)\). \(f(x-1)\): \((3,5)\). \(-f(x)\): \((2,-5)\). \(f(-x)\): \((-2,5)\). \(2f(x)\): \((2,10)\).

3. Three families of graphs

Applying a stretch and two shifts to a basic function gives a whole family. The parameters tell you the key features without any calculation:

FamilyComes fromKey features
\(y=a(x-p)^n+k\)\(x^n\)the point \((0,0)\) moves to \((p,k)\); for \(n=2\) this is the vertex
\(y=a\sqrt{x-p}+k\)\(\sqrt x\)starts at \((p,k)\); domain \(x\ge p\); rises if \(a\gt 0\), falls if \(a\lt 0\)
\(y=\dfrac{a}{x-p}+k\)\(\tfrac1x\)asymptotes \(x=p\) and \(y=k\)
Example 2

For \(y=\dfrac2{x-1}+3\), find the asymptotes and the points where the graph meets the axes.

Solution.

Asymptotes: \(x=1\) and \(y=3\).

y-axis: \(x=0\Rightarrow y=-2+3=1\).

x-axis: \(\dfrac2{x-1}=-3\Rightarrow x-1=-\tfrac23\Rightarrow x=\tfrac13\).

Example 3

For \(y=-\sqrt{x+4}+2\), find the domain, the starting point and the root.

Solution.

Domain \(x\ge-4\); starting point \((-4,2)\); since \(a=-1\lt 0\) the graph falls.

\(\sqrt{x+4}=2\Rightarrow x+4=4\Rightarrow x=0\). The root is \(x=0\) (also the y-intercept).

4. Adding, multiplying and dividing functions

From two functions \(f\) and \(g\) we can build \(f+g\), \(f-g\), \(f\cdot g\) and \(\dfrac fg\) by doing the operation on the values: \((f+g)(x)=f(x)+g(x)\), and so on.

Domain: the new function is defined only where both \(f\) and \(g\) are defined. For \(\dfrac fg\), also remove the points where \(g(x)=0\).

Example 4

\(f(x)=\sqrt{x}\) and \(g(x)=x-4\). Find the domain of \(\dfrac fg\).

Solution.

\(f\) needs \(x\ge0\); the denominator needs \(x\ne4\). Domain: \(x\ge0,\ x\ne4\).

Sign of a product or quotient. \(f\cdot g\) and \(\dfrac fg\) are positive where \(f\) and \(g\) have the same sign, and negative where the signs differ. So a sign table of \(f\) and \(g\) gives the sign of the result.

5. The function \(\dfrac1f\)

The function \(g=\dfrac1f\) can be sketched from the graph of \(f\):

  • Where \(f(x)=0\), \(g\) is not defined and usually has a vertical asymptote.
  • \(g\) has the same sign as \(f\).
  • Where \(|f|\) is large, \(g\) is close to 0. If \(|f|\to\infty\), then \(y=0\) is an asymptote of \(g\).
  • Where \(f\) increases, \(g\) decreases, and the other way round (on intervals where \(f\ne0\)). A minimum of \(f\) becomes a maximum of \(g\).
  • Where \(f=1\) or \(f=-1\), \(g\) has the same value.
Example 5

Describe \(g(x)=\dfrac1{x^2-4}\) using \(f(x)=x^2-4\).

Solution.

Roots of \(f\) at \(\pm2\): vertical asymptotes \(x=2\) and \(x=-2\).

\(f\to\infty\) as \(|x|\to\infty\): horizontal asymptote \(y=0\).

\(f\lt 0\) for \(-2\lt x\lt 2\), so \(g\lt 0\) there. \(f\) has a minimum \((0,-4)\), so \(g\) has a maximum \((0,-\tfrac14)\) between the asymptotes.

\(f\) is even, so \(g\) is even.

6. Common mistakes

  • Moving \(f(x-3)\) to the left. The graph moves 3 units to the right.
  • Reading the asymptotes of \(\dfrac{2}{x+1}-4\) as \(x=1\), \(y=4\). They are \(x=-1\) and \(y=-4\).
  • Confusing \(-f(x)\) (reflect in the x-axis) with \(f(-x)\) (reflect in the y-axis).
  • Forgetting to remove the zeros of the denominator from the domain of \(\dfrac fg\).
  • Thinking that \(\dfrac1f\) has a root where \(f\) has an asymptote. \(\dfrac1f\) gets close to 0 there, but a fraction \(\dfrac1{f}\) is never exactly 0.

7. Check yourself

Short exercises to check that you understood the explanation. Try each one before you open the solution. For more practice, go to the workbook.

  1. How is \(y=(x+4)^2\) obtained from \(y=x^2\)?

    Show solution

    Shift 4 units to the left.

  2. Find the asymptotes of \(y=\dfrac1{x-5}-2\).

    Show solution

    \(x=5\) and \(y=-2\).

  3. \((3,-1)\) is on the graph of \(f\). Which point is on the graph of \(f(x)+2\)?

    Show solution

    \((3,1)\)

  4. What does the graph of \(-f(x)\) look like compared with the graph of \(f\)?

    Show solution

    It is the reflection of the graph of \(f\) in the x-axis.

  5. Find the domain of \(\dfrac{\sqrt{x-1}}{x-3}\).

    Show solution

    \(x\ge1\) and \(x\ne3\).

  6. \(f(x)=x+2\) and \(g(x)=x-2\). Find \((f\cdot g)(x)\).

    Show solution

    \((x+2)(x-2)=x^2-4\)

  7. Where does \(\dfrac1f\) have a vertical asymptote if \(f(x)=x-5\)?

    Show solution

    \(x=5\), the root of \(f\).

  8. The graph of \(y=a\sqrt x\) passes through \((4,6)\). Find \(a\).

    Show solution

    \(a\cdot2=6\Rightarrow a=3\)
