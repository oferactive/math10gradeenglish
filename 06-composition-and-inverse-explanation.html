Composition and Inverse Functions

1. Composition: a function inside a function

In the composition \(f(g(x))\) we first apply \(g\) to \(x\), and then apply \(f\) to the result. \(g\) is the inner function and \(f\) is the outer function.

\(x\ \xrightarrow{\ g\ }\ g(x)\ \xrightarrow{\ f\ }\ f(g(x))\)
first the inner function, then the outer one
Example 1

\(f(x)=x^2\) and \(g(x)=x+3\). Find \(f(g(x))\) and \(g(f(x))\), and compute both at \(x=1\).

Solution.

\(f(g(x))=f(x+3)=(x+3)^2\); at \(x=1\): \(16\).

\(g(f(x))=g(x^2)=x^2+3\); at \(x=1\): \(4\).

The order matters: in general \(f(g(x))\ne g(f(x))\).

Recognising a composition. Ask: "If I computed this on a calculator, which operation would I do last?" That operation is the outer function. For \(\sqrt{x^2+1}\), the last step is the square root: inner \(x^2+1\), outer \(\sqrt u\).

FunctionInner \(g(x)\)Outer \(f(u)\)
\((3x-1)^5\)\(3x-1\)\(u^5\)
\(\sqrt{x^2+1}\)\(x^2+1\)\(\sqrt u\)
\(|x-4|\)\(x-4\)\(|u|\)
\(\dfrac1{x+2}\)\(x+2\)\(\dfrac1u\)

2. The functions \(|f(x)|\), \((f(x))^2\) and \(\sqrt{f(x)}\)

\(|f(x)|\): where \(f\ge0\) nothing changes; where \(f\lt 0\) the graph is reflected up above the x-axis.

\((f(x))^2\): never negative; it has the same roots as \(f\), and they become roots of even multiplicity (the graph touches the axis).

\(\sqrt{f(x)}\): defined only where \(f(x)\ge0\); it has the same roots as \(f\), and it increases where \(f\) increases.

Example 2

Find the domain of \(y=\sqrt{4-x^2}\) and describe its graph.

Solution.

\(4-x^2\ge0\Rightarrow -2\le x\le2\).

If \(y=\sqrt{4-x^2}\) then \(y\ge0\) and \(y^2=4-x^2\), so \(x^2+y^2=4\): the graph is the upper half of the circle with centre \(O\) and radius 2.

3. Inverse functions

The inverse of \(f\), written \(f^{-1}\), undoes \(f\): if \(f(a)=b\), then \(f^{-1}(b)=a\). Applying one after the other brings us back: \(f^{-1}(f(x))=x\) and \(f(f^{-1}(x))=x\).

When does an inverse exist? Only when \(f\) never gives the same value twice (it is one-to-one). On a graph: every horizontal line meets the graph at most once. A function that is always increasing or always decreasing is one-to-one.

For example \(x^2\) is not one-to-one, because \(2^2=(-2)^2\). But if we keep only \(x\ge0\), it is.

Finding the formula: write \(y=f(x)\), swap \(x\) and \(y\), and solve for \(y\).

Example 3

Find the inverse of \(f(x)=2x-3\).

Solution.

\(x=2y-3\Rightarrow y=\dfrac{x+3}2\). So \(f^{-1}(x)=\dfrac{x+3}2\).

Check: \(f\left(\dfrac{x+3}2\right)=2\cdot\dfrac{x+3}2-3=x\) ✓

Example 4

Find the inverse of \(f(x)=x^2+1\), \(x\ge0\).

Solution.

\(x=y^2+1\Rightarrow y^2=x-1\Rightarrow y=\sqrt{x-1}\) (we take the positive root, because \(y\ge0\) in the original domain).

\(f^{-1}(x)=\sqrt{x-1}\), \(x\ge1\).

Domain and range swap: the domain of \(f^{-1}\) is the range of \(f\), and the range of \(f^{-1}\) is the domain of \(f\).

4. The graph of the inverse

If \((a,b)\) is on the graph of \(f\), then \((b,a)\) is on the graph of \(f^{-1}\). Swapping the coordinates is a reflection in the line \(y=x\). So:

\(\text{graph of } f^{-1} = \text{reflection of the graph of } f \text{ in } y=x\)

Some functions are their own inverse. Their graph is symmetric about \(y=x\). Example: \(f(x)=\tfrac1x\), because swapping gives \(x=\tfrac1y\Rightarrow y=\tfrac1x\).

5. Square roots, cube roots and \(\sqrt{x^2}=|x|\)

FunctionInverseNotationDomain of the inverse
\(x^2\), \(x\ge0\)\(\sqrt x\)\(x^{1/2}\)\(x\ge0\)
\(x^3\), all \(x\)\(\sqrt[3]x\)\(x^{1/3}\)all \(x\) (for example \(\sqrt[3]{-8}=-2\))

Because \(x^3\) is one-to-one on all real numbers, \(\sqrt[3]{x^3}=x\) for every \(x\).

For the square root it is different. \(\sqrt{(-5)^2}=\sqrt{25}=5\), not \(-5\). The square root always returns the non-negative number:

\(\sqrt{x^2}=|x|\qquad\text{but}\qquad(\sqrt x)^2=x\ \text{ only for } x\ge0\)
Example 5

Solve \(\sqrt{(x-3)^2}=x\).

Solution.

\(\sqrt{(x-3)^2}=|x-3|\). Since the left side is non-negative, \(x\ge0\).

\(x-3=x\) is impossible; \(3-x=x\Rightarrow x=1.5\).

Check: \(|1.5-3|=1.5\) ✓

6. Common mistakes

  • Computing \(f(g(x))\) in the wrong order: \(g\) is applied first.
  • Reading \(f^{-1}(x)\) as \(\dfrac1{f(x)}\). The inverse function undoes \(f\); it is not the reciprocal.
  • Finding an "inverse" of a function that is not one-to-one, such as \(x^2\) on all real numbers. First restrict the domain.
  • Writing \(\sqrt{x^2}=x\). It is \(|x|\).
  • Forgetting that \(\sqrt{f(x)}\) needs \(f(x)\ge0\): the domain can be much smaller than the domain of \(f\).
  • Saying that the cube root of a negative number does not exist. \(\sqrt[3]{-27}=-3\).

7. Check yourself

Short exercises to check that you understood the explanation. Try each one before you open the solution. For more practice, go to the workbook.

  1. \(f(x)=x+2\), \(g(x)=x^2\). Compute \(f(g(3))\) and \(g(f(3))\).

    Show solution

    \(f(9)=11\) and \(g(5)=25\).

  2. Name the inner and outer functions of \(\sqrt{2x+5}\).

    Show solution

    Inner \(2x+5\), outer \(\sqrt u\).

  3. Find the inverse of \(f(x)=3x+6\).

    Show solution

    \(x=3y+6\Rightarrow f^{-1}(x)=\dfrac{x-6}3=\dfrac x3-2\)

  4. \((2,9)\) is on the graph of \(f\). Which point is on the graph of \(f^{-1}\)?

    Show solution

    \((9,2)\)

  5. Compute \(\sqrt{(-7)^2}\).

    Show solution

    \(|-7|=7\)

  6. Compute \(\sqrt[3]{-64}\).

    Show solution

    \(-4\), because \((-4)^3=-64\).

  7. Is \(f(x)=x^2-1\) one-to-one on all real numbers?

    Show solution

    No: \(f(1)=f(-1)=0\).

  8. Find the domain of \(\sqrt{x^2-1}\).

    Show solution

    \(x^2\ge1\Rightarrow x\le-1\) or \(x\ge1\).
